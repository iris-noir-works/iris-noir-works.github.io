## App Development Git SSOT Rule

このrepositoryのアプリ・ソフトウェア開発とGit操作では、毎回
[App Development Git SSOT Rule](.repo-policy/RULE.md)を読み、必ず適用する。
`app-development-git-ssot` Skillを自動適用し、検証済みと主張する前に
`verification-before-completion` Skillも適用する。
commit / push前にbranch、HEAD、working tree、verification結果、Evidence / secret除外を確認する。

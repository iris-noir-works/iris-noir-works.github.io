# Privacy & Support

アプリ共通のプライバシーポリシー／サポートページ（GitHub Pages、`main` の root から配信）。

- Top: `https://iris-noir-works.github.io/`
- 使い方（アプリ別）: `https://iris-noir-works.github.io/konnahi/` / `https://iris-noir-works.github.io/workingman/`（App Store Connect のサポートURL）
- Privacy Policy: `https://iris-noir-works.github.io/privacy.html`（アプリ別：`#konnahi` / `#workingman`）
- Support: `https://iris-noir-works.github.io/support.html`（アプリ別：`#konnahi` / `#workingman`）

App Store Connect には、アプリごとにアンカー付きの URL を登録する。
アプリを追加するときは、`privacy.html` / `support.html` / `index.html` に同じ形の項目を足す。

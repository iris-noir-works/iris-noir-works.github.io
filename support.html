お問い合わせ方法

ご連絡は GitHub Issues をご利用ください。タイトルの先頭にアプリ名を入れてください（例：「[WorkingMan] 〜」）。

GitHub Issuesを開く

お問い合わせ時にあると助かる情報

  • アプリ名とバージョン
  • 端末の機種（iPhone / iPad）と iOS のバージョン
  • 発生した画面や操作

WorkingMan

WorkingMan に関する不具合報告・ご質問は、GitHub Issues からご連絡ください。

GitHub Issuesを開く

ご連絡の際は、アプリのバージョン、端末の機種（iPhone / iPad / iPhone Duo）、iOS のバージョン、 発生した画面や操作があると確認しやすくなります。

  • ご利用には Apple Music のサブスクリプションと、「メディアと Apple Music」へのアクセス許可が必要です。許可は「設定」アプリ ▸ WorkingMan から変更できます。
  • 操作音は「設定」アプリ ▸ WorkingMan の「Sound Effects」でオフにできます。
  • 使い方はWorkingMan の使い方をご覧ください。

個人情報や機密情報は GitHub Issues へ投稿しないでください。

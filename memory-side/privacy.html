プライバシーポリシー

最終更新日：2026年11月7日

Apple Music へのアクセス

MEMORY SIDE は、利用者の許可を得て MusicKit を通じてミュージックライブラリを読み取り、表示・再生します。DISCOVER でカタログを検索するときは、検索語が MusicKit を通じて Apple に送られます。アートワーク画像の表示には、MusicKit が提供する画像URLへの通信を使います。Apple による情報の取り扱いについては Apple のプライバシーポリシーをご覧ください。

端末に保存する情報

プレーヤーの状態や編集テープ、カセットの見た目、本体カラー、背景、操作音などの設定は端末に保存されます。

アカウントと広告

MEMORY SIDE 独自のアカウント登録はありません。広告 SDK やアクセス解析 SDK は使用していません。

お問い合わせ

GitHub Issues からご連絡ください。投稿は公開されるため、個人情報や機密情報を含めないでください。
